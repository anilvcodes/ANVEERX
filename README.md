
# ANVEERX – Global Ultra Running & Marathon

### GO BEYOND LIMITS. 🇮🇳

**ANVEERX** is a modern, responsive ultra-running and marathon website founded in Gonda, Uttar Pradesh, India.

Our vision is to connect runners, organize endurance events, and build a running community from Gonda to India and the world.

> Born in Gonda. Built for the World.

---

## 🌍 About ANVEERX

ANVEERX is an ambitious running and endurance sports platform for beginners, professional athletes, marathon runners, and ultra-runners.

Our mission is to promote running culture, endurance, fitness, discipline, and sports participation across India and internationally.

## ✨ Features

- Responsive mobile-first website
- Premium black and orange design
- 5K, 10K, 21K, 42K, 50K and 100K race categories
- Runner registration enquiry form
- WhatsApp integration
- Strava integration entry point
- Runner leaderboard
- Running community section
- Mobile navigation
- Indian-inspired brand identity
- International expansion vision

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts
- WhatsApp Click-to-Chat
- Strava API (future integration)

## 🚀 Installation

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate to the project

```bash
cd anveerx
```

### 3. Open the website

Open `index.html` in your browser.

You can also use the Live Server extension in VS Code.
